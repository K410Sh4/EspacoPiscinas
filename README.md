# Espaço Piscina — loja-vitrine digital

Site estático para apresentar categorias de piscinas, acessórios e serviços e receber pedidos de orçamento por WhatsApp. Projeto inicial criado seguindo o Protocolo UX/UI V3.3.

> **Atenção:** demonstração comercial a ser validada pela empresa antes de divulgação oficial. Catálogo ilustrativo por categorias, sem preços, estoque ou pedidos pagos.

A página é hospedável no GitHub Pages. Consulte as instruções de publicação neste README após a implementação.
